# Leo Olsen Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.  
The project showcases selected web projects, frontend development skills, responsive layouts and a clean multi-page website structure.

## Live Demo

[View Live Website](https://leogos.github.io/leo-portfolio/)

## Overview

This portfolio was created to present my work as a fullstack developer with a strong focus on frontend structure, responsive design and clean user interfaces.

The website includes a home page, projects page and contact page. Each section is designed to highlight practical development skills, project presentation and a professional digital presence for employers, clients and collaborators.

## Features

- Responsive multi-page website
- Home, Projects and Contact pages
- Modular CSS file structure
- Semantic HTML layout
- JavaScript-powered interactions
- Page loader
- Responsive navigation and modal menu
- Project cards with live demo and repository links
- Contact form layout
- Optimized visual presentation for desktop, tablet and mobile screens

## Built With

- HTML5
- CSS3
- JavaScript
- GitHub
- Lighthouse
- Prettier

## CSS Structure

The CSS is organized into modular section-based files and imported through a main `styles.css` entry file.

This structure keeps the codebase easier to read, maintain and extend across multiple pages. It also reflects a development workflow where global styles, layout styles, page styles and component styles are separated clearly.
